JavaScript

JavaScript makes the application interactive. It gets the drink name entered by the user, sends the API request, receives the drink information, and places the results on the webpage.

TheCocktailDB API

TheCocktailDB API provides the cocktail data used by the application, including drink names, images, and preparation instructions.

Fetch API

JavaScript's fetch() method is used to communicate with TheCocktailDB API and retrieve cocktail information.
